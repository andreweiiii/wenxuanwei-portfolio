PicKape — Coffee Quality & Traceability System

PicKape is a farm-to-cup management app for coffee growers. Farmers record harvest batches in the field, scan them, track quality, and hand every bean a clear traceable story — even on farms where the network is unreliable.

Visit the live website

Problem

Farmers tracked harvests with paper logs. Records got lost, quality was judged by feel, and there was no way to trace a batch back to a farm or a harvest date.

Solution

A Flutter app paired with a Node.js API. Batches are created on the phone, stored locally first, then synced when a connection is available. Every batch carries farm and harvest details for full traceability.

Key features

Offline-first sync

Batches save to a local SQLite store first. A sync manager pushes and pulls through the API when the network returns, so no work is lost.

Live dashboard

The home screen streams assigned lots and harvest totals in real time, so field data shows up as it happens.

Farm traceability

Every batch links back to its farm and harvest details, giving each lot a clean, auditable story from field to cup.

Quality sorting (PQI)

A Preliminary Quality Indicator guides growers toward better sorting, with a clear note that the tool assists and can make mistakes.

QR batch scanning

Growers scan a batch in the field with the phone camera. Each scan is stored and linked to the batch record.

Guarded account flow

Password resets and profile changes run through an approved, moderated flow instead of open endpoints.
